# Asistente-Virtual-Angela
Asistente virtual en donde se crean algunas funciones en las que puedes interactuar, como también poder abrir youtube, google. un pequeño proyecto, todo se utilizó un lenguaje python. En lo que respecta a los comandos, son las palabras clave para que puedas asignar tareas a Angela. 

En los botones como sus mismos nombres lo dicen, puedes agregar archivos, agregar aplicaciones, agregar paginas o agregar contactos. y quedarán filtrados en la base de datos. 

En la parte donde está en blanco, puedes escribir algunas palabras o textos, y Angela puede reproducirlo en idioma Española, Mexicana o en Ingles
